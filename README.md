## Agentic Engineering

I'm currently exploring the emerging field of **Agentic Engineering**.

Rather than using AI only to generate code, I'm interested in how developers can build structured engineering workflows around AI agents.

Areas I'm exploring include:

* AI coding agents
* Agent skills
* Model Context Protocol (MCP)
* Agent memory
* Context engineering
* Tool integration
* Multi-agent workflows
* Knowledge graphs for codebases
* Spec-driven development
* Research-first development
* Automated testing and validation
* Secure agent workflows

The focus is on using AI as part of a **reliable software-engineering process**, with the developer remaining responsible for architecture, decisions, security and quality.
