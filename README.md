I'm a **Software Developer Intern at Africa Code Academy** and a **Software Engineering student at Botho University**.

I build web applications and real-world software systems while continuously expanding my understanding of what happens beyond the code — architecture, databases, security, infrastructure, automation and deployment.

My current journey is moving through three connected areas:

<p align="center">

**Software Development**
↓
**Software Engineering**
↓
**Agentic Engineering**

# 🤖 Exploring Agentic Engineering

I'm currently going deeper into **AI-assisted and agentic software engineering**.

The interesting part for me isn't simply asking AI to write code.

It's understanding how developers can create an engineering environment where AI agents can:

```text
Understand
    ↓
Research
    ↓
Plan
    ↓
Use Tools
    ↓
Implement
    ↓
Test
    ↓
Review
    ↓
Improve
```
